# 接线图与常见接线错误

## 1. OLED（SSD1306，I2C）

| OLED 引脚 | ESP32-S2 | 备注 |
|-----------|----------|------|
| VCC | 3V3 | 部分模块标 VDD，5V 也能扛但建议 3.3V |
| GND | GND | 共地必须接，否则 I2C 数据乱跳 |
| SDA | GPIO8 | 可在 menuconfig 改 |
| SCL | GPIO9 | 可在 menuconfig 改 |

```
SSD1306          ESP32-S2-DevKitC-1
 VCC  -----------  3V3
 GND  -----------  GND
 SDA  -----------  GPIO8
 SCL  -----------  GPIO9
```

**地址确认**：模块背面通常有一个 `0x78` / `0x7A` 的贴片电阻焊盘。
电阻焊在 0x78 一侧 → 7 位地址 **0x3C**；焊在 0x7A 一侧 → **0x3D**。
地址不对时日志会报 `init cmd failed` 或 `first flush failed`。

## 2. 蜂鸣器（有源，高电平触发）

### 方案 A：三极管驱动（推荐）

```
        +3V3 ──────────────┐
                            │
                          ┌─┴─┐
                          │蜂鸣器│   有源蜂鸣器（注意正负极，长脚为正）
                          └─┬─┘
                            │  C
    GPIO10 ────[1kΩ]────────┤      NPN：S8050 / 2N3904 / 2N2222 都行
                            │  E
        GND ────────────────┘

    建议在蜂鸣器两端并联一只 1N4148（阴极接 +3V3 一侧）吸收反峰。
```

GPIO 高电平 → 三极管导通 → 蜂鸣器响，**符合"高电平触发"**。

### 方案 B：直接驱动（仅限小电流蜂鸣器临时验证）

```
    GPIO10 ──── 蜂鸣器(+)      蜂鸣器(-) ──── GND
```

⚠️ ESP32-S2 单个 GPIO 建议持续电流不超过 ~20mA（绝对最大 40mA）。
有源蜂鸣器常见 20~30mA，直接驱动会拉低电压，长期可能损伤 IO。正式用请走方案 A。

## 3. 按键

直接用板载 **BOOT 键（GPIO0）**，不用外接任何东西：按下 = 拉低，松开 = 上拉为高。

想外接按键：

```
    GPIO0 ──── 按键 ──── GND      （内部已使能上拉，无需外接电阻）
```

⚠️ GPIO0 是 strapping 引脚：**上电瞬间不能按住**，否则芯片进下载模式不跑程序。

## 4. 最常见的 5 个接线错误

1. **忘记共地** —— OLED、蜂鸣器、开发板三者的 GND 必须连在一起。
2. **SDA / SCL 接反** —— 现象是 I2C 一直 timeout。
3. **地址不对** —— 在 0x3C 和 0x3D 之间切换试一次（`idf.py menuconfig` 里改）。
4. **把有源蜂鸣器当无源用** —— 有源蜂鸣器内部有振荡源，给它 PWM 只会"滋滋"响且音调不变；
   要播放旋律请换无源蜂鸣器并改用 LEDC 输出。
5. **把 OLED 接到 GPIO26~32** —— 这些脚被板载 Flash/PSRAM 占用，永远不会工作。
